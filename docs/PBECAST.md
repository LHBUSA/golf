# PBEcast Golf

Responsive command center foundation includes original decorative contours and unavailable states. It is not actual routing, observed coordinates or live action.

Production desktop: leaderboard ticker, active-hole/course visualization, intelligence rail. Player card: verified identity/position/tournament and round score/source current hole/group/tee time/actual scorecard/recent holes. Mobile prioritizes score and hole facts before pulse/history.

Active hole uses sourced number/par/yardage/layout plus documented difficulty/distribution/sample. Shots only show actual permitted events and supplied club/lie/result/distance/unit/remaining distance. Coordinates need a known frame and approved routing. Tee times/scorecards cannot infer exact player position.

Pulse diffs comparable source snapshots/events: lead changes, eagles, observed runs, cut status and movement. Delayed data exposes as_of/latency. Unknown status/leader remains unavailable. Projected cuts need source-projected label or versioned methodology. Advanced view gates server-side via All Access. Neither feed nor fake preview exists today.
